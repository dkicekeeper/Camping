# Сквозные темы

Всё, что не принадлежит одной вкладке, но влияет на все.

## Онбординг

Цель: за 60 секунд довести до первой пользы и не требовать лишнего.

1. Приветствие — 2–3 экрана о ценности (карта мест, запреты, журнал поездок) — `OnboardingPageContainer`.
2. Язык: RU / KK / EN (по умолчанию — язык системы).
3. Интересы: рыбалка (сейчас), кемпинг и горы (отметка «скоро» — для будущих рассылок).
4. Геолокация — с объяснением «зачем» до системного запроса.
5. Вход через Apple или Google (можно пропустить — гостевой режим).
6. Username и аватар.
7. Друзья: пригласить по ссылке или QR; «найти из контактов» — с подтверждением телефона.
8. Уведомления — с объяснением (`NotificationPermissionView`), лучше в момент первой пользы
   (после первого чекина или сохранения места).
9. Предложение скачать офлайн-карту ближайшего региона.

## Аккаунт и вход

- **Регистрация — Sign in with Apple и Google** (решение 2026-09-29, без затрат на SMS).
- **Номер телефона — в момент ценности**, а не при регистрации:
  - «Найти друзей из контактов» — сопоставление работает только по подтверждённым номерам;
  - публикация первого публичного места — защита от спама.
  Для личных мест, чекинов, поездок и уловов номер не нужен.
- Подтверждение номера — код через Telegram Gateway ($0,01), без Telegram — SMS; включаем к бете.
  Пока выключено — поиск по контактам скрыт, публичные места новых аккаунтов проходят премодерацию.
  Детали и защита от SMS-фрода — в [архитектуре бэкенда](../03-architecture/02-backend.md#авторизация).
- В настройках — «не находить меня по номеру телефона».
- Удаление аккаунта из приложения (требование App Store).
- Username уникальный, латиница, цифры, `_`, `.`; имя — любое.
- Согласие на обработку персональных данных при регистрации (закон РК); для беты — с пунктом о
  хранении данных за пределами РК.

## Гостевой режим

Без аккаунта можно смотреть карту, публичные места, статьи, правила, справочник, пользоваться
чеклистами (локально). Для чекинов, мест, отзывов, тредов, поездок и друзей нужен аккаунт.
Это и снижает барьер входа, и соответствует требованию App Store не требовать вход для функций,
которым он не нужен.

## Друзья и социальные связи

- **Модель — взаимная дружба** (запрос → принятие), как ВКонтакте или Facebook. Видимость
  «друзья» работает только на взаимных связях — это проще и понятнее для приватности.
- Подписки на публичных авторов (без взаимности) — 2.0, вместе с партнёрскими аккаунтами
  (гиды, платники, бренды).
- Приглашения: личная ссылка и QR (открывает профиль и предлагает дружбу); отметка друзей в
  поездке — повод пригласить тех, кого ещё нет в приложении (1.1).
- Блокировка: заблокированный не видит мой контент и не может со мной взаимодействовать; я не
  вижу его контент.

## Приватность и видимость

### Уровни видимости

| Уровень | Кто видит | Релиз |
|---------|-----------|-------|
| **Все** | Любой пользователь и гость (для публичных мест) | MVP |
| **Друзья** | Взаимные друзья | MVP |
| **Выбранные друзья** | Списки: «Близкие», «Рыбалка с отцом» и т.п. | 1.1 |
| **Только я** | Автор | MVP |

### Где задаётся

| Объект | По умолчанию (меняется в настройках) | Особенности |
|--------|--------------------------------------|-------------|
| Место | Выбор при создании, без скрытого значения по умолчанию; запоминается последний | Приблизительная точка (круг ~1 км) для «все» и «друзья» |
| Поездка | Друзья | Трек обрезается зонами приватности |
| Чекин | Как у поездки или «Друзья» | Не может быть видимее места |
| Улов | Как у поездки | Можно показать улов, скрыв место |
| Медиа | Как у родителя (чекин, поездка, отзыв) | EXIF-геоданные удаляются для публичных |
| Отзыв, тред, сообщение | Всегда публичны | Только в публичных местах |
| Маршрут | Только я | Можно поделиться ссылкой |

### Правила

1. **Не видимее родителя.** Чекин, улов и фото не могут показать место шире, чем видимость
   самого места. Если место приватное, а поездка — для друзей, друзья видят поездку, но вместо
   места — **«Секретное место»** (без координат, трек на этом участке скрыт).
2. **Зоны приватности:** начало и конец трека в радиусе 200–1000 м от заданных точек (дом, дача)
   не показываются другим.
3. **Публичное место — общее.** Когда в публичном месте появились чужие отзывы, чекины и фото,
   автор не может сделать его приватным или удалить — только запросить удаление через модерацию.
   Приватное место можно сделать публичным в любой момент.
4. **Изменение видимости** применяется ко всем копиям: к ленте, поиску, карте, шарингу. Уже
   отправленные картинки-карточки отозвать нельзя — предупреждаем при шаринге.
5. **Геоданные в фото** из галереи используются для привязки к месту, но из публичных файлов удаляются.

## Геймификация

Задача — поощрять **вклад в общую базу**, а не просто активность.

| Механика | Описание | Релиз |
|----------|----------|-------|
| **Очки вклада** | Публичное место (после модерации) — 20, фото — 5, отчёт с условиями — 5, отзыв — 10, принятая правка — 10, ответ в треде, отмеченный «полезно», — 5 | MVP |
| **Уровни участника** | Новичок → Знаток → Эксперт → Хранитель; высокие уровни проверяют правки (1.1) | MVP (уровни), 1.1 (права) |
| **Бейджи** | Первые шаги, водоёмы, дистанция, ночёвки, вклад | MVP (8–10 шт.) |
| **Смотритель места** | Больше всего подтверждённых чекинов за 60 дней — аналог «мэра» из Swarm | 1.1 |
| **Рекорды места** | Самый крупный улов вида на месте (подтверждённый чекин, фото) | 1.1 |
| **Серии** | Недели подряд с поездкой (с «заморозкой» на запреты и зиму) | 1.1 |
| **Челленджи** | «10 водоёмов за сезон», «Чистый берег» (фото с собранным мусором); позже — спонсорские | 2.0 |

Защита от накруток: очки только за контент, прошедший проверку; лимиты в день; неподтверждённые
чекины не участвуют в соревновательных механиках.

## Модерация

**Обязательное для App Store (UGC):** фильтр нежелательного контента, жалобы на контент и
пользователей, блокировка, контакты для обратной связи, реакция на жалобы.

| Слой | Что делает | Релиз |
|------|------------|-------|
| Автофильтры | Мат и оскорбления (RU / KK / EN), спам и ссылки, NSFW на фото | MVP |
| Лимиты | Ограничение частоты мест, отзывов, сообщений для новых аккаунтов | MVP |
| Дубли | Проверка похожих мест при создании; слияние в админке | MVP |
| Жалобы | На место, отзыв, фото, сообщение, пользователя; очередь в админке | MVP |
| Выборочная премодерация | Первые N публичных мест нового пользователя — через редакцию | MVP |
| Флаги браконьерства | Улов в зоне запрета, сети и запрещённые орудия на фото → проверка; публично не показываем точку | MVP |
| Доверенные участники | Проверка правок и жалоб пользователями высокого уровня | 1.1 |

**Правила сообщества** (на трёх языках): без браконьерства и хвастовства им, без мусора, без
раскрытия чужих приватных мест, уважение к другим.

## Админка и редакция

Нужна с первого дня — без неё не наполнить базу к запуску.

- **Места и зоны:** создание, редактирование, слияние дублей, импорт (OpenStreetMap), геометрии
  водоёмов, участков рек, нацпарков, погранзоны.
- **Правила:** редактор ограничений (зона или участок, даты, что запрещено, штраф, источник,
  год, тексты на 3 языках), публикация новой версии на год.
- **Контент:** статьи (Markdown + фото), шаблоны чеклистов, справочник рыб, подборки мест.
- **Модерация:** очередь жалоб, премодерация, правки, флаги; действия: скрыть, удалить,
  предупредить, заблокировать.
- **Пользователи:** поиск, блокировка, выдача ролей (редактор, амбассадор).
- **Переводы:** статус перевода каждого материала (RU / KK / EN).

## Наполнение к запуску

Готовит **владелец продукта**, дальше подключается **сообщество** (краудсорсинг: места, отчёты,
отзывы, правки). Амбассадоры — первые активные участники сообщества.

| Что | Цель к бете | Источники |
|-----|-------------|-----------|
| Публичные места | 200+ | Свои поездки, амбассадоры, OpenStreetMap (водоёмы, нацпарки; лицензия ODbL), официальные перечни платных водоёмов |
| Зоны и правила | Балхаш-Алакольский бассейн, Иле-Алатауский и Алтын-Эмельский нацпарки, погранзона | Приказы (adilet.zan.kz), egov.kz, сайты нацпарков |
| Статьи | 15–20 × 3 языка | Редакция, амбассадоры |
| Чеклисты | 6 × 3 языка | Редакция |
| Виды рыб | ~20 × 3 языка | Редакция + эксперт |

**Амбассадоры:** 30–50 активных рыбаков из Telegram-чатов и форумов: ранний доступ в бете,
бейдж «Основатель», прямой канал с командой. Их задача — места, отчёты, отзывы до запуска.

Чужие базы (FisherMap, 2ГИС и т.д.) **не парсим** — юридический риск.

## Локализация

- Языки: **русский, казахский (кириллица — решение 2026-09-29), английский**. Язык интерфейса — из
  системы, можно сменить в приложении.
- Строки интерфейса — String Catalogs (`.xcstrings`); плюрализация (в русском и казахском разные правила).
- Справочники (виды рыб, типы мест, атрибуты, категории экипировки) — переводы на сервере.
- Названия мест и зон: основное + переводы (RU / KK / EN) для редакционных объектов; у
  пользовательских — одно название на языке автора.
- Пользовательский контент не переводим (автоперевод — 2.0).
- Форматы: даты, числа, единицы (км, кг, см, °C), валюта ₸.
- Правила — ссылка на первоисточник на языке пользователя, если он есть (RU / KK).

## Офлайн и синхронизация

- **Доступно офлайн:** скачанные карты, мои и сохранённые места, недавние страницы мест, слой
  правил (последняя версия), мои поездки и треки, экипировка, чеклисты, сохранённые статьи,
  справочник рыб.
- **Создаётся офлайн и уходит позже:** чекины, уловы, места, фото, поездки, правки чеклистов.
- Индикатор «ожидает отправки»; ретраи; загрузка фото — только по Wi-Fi (настройка).
- Конфликты: для личных данных — последняя правка побеждает; для общих (места) — правка уходит
  как предложение.

## Аналитика

- Продуктовые события по воронкам: онбординг → первый чекин / первая поездка → первый друг → неделя 2.
- Без передачи точных координат в аналитику; идентификаторы — псевдонимные.
- Сервис аналитики выбираем на Этапе 3 с учётом хранения данных в РК.

## Юридическое

- Пользовательское соглашение, политика конфиденциальности, правила сообщества — RU / KK / EN.
- Согласие на сбор и обработку ПД; хранение ПД граждан РК на территории РК.
- Дисклеймеры: правила — справочные, первоисточник — официальные документы; безопасность в
  горах и на воде — ответственность пользователя; маршруты пользователей не проверяются.
- Возрастной рейтинг App Store с учётом UGC; минимальный возраст — уточнить у юриста.
- Лицензии данных: OpenStreetMap (ODbL, указание авторства), спутниковые снимки (условия
  поставщика).

## Доступность

Dynamic Type (DesignKit уже поддерживает через Inter + `relativeTo`), VoiceOver для ключевых
сценариев (чекин, поездка, страница места), Reduce Motion (есть в `AppAnimation`), контраст на
картах и в тёмной теме.

## Задел под партнёров

В MVP не делаем, но закладываем в модель данных:
- тип аккаунта (пользователь / партнёр / редакция) и связь «партнёр ↔ место» (владелец);
- поле «спонсор» у подборок и будущих челленджей;
- метка «партнёрский материал» у статей.
