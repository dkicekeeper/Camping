## Принципы продукта

1. **Польза без сети друзей.** Приложение полезно одному человеку с первого дня: журнал поездок и
   уловов, запись трека, офлайн-карта, правила, чеклисты. Это ответ на проблему холодного старта.
2. **Вклад за 10 секунд.** Чекин или отчёт — фото и пара тапов. Всё остальное — по желанию.
3. **Приватность — выбор пользователя.** У каждого места, поездки, улова и чекина есть видимость.
   Можно похвастаться уловом и не раскрыть точку.
4. **Офлайн по умолчанию.** Всё, что нужно на месте, работает без связи; созданное без сети
   отправится, когда сеть появится.
5. **Локальная правда.** У правил и запретов всегда есть источник и дата актуальности.
6. **Сообщество важнее контента.** Механики поощряют вклад (очки, статусы, «смотрители» мест).
7. **Три языка с первого дня.** Интерфейс, справочники и редакционный контент — RU / KK / EN.

## Информационная архитектура

```
TabView (iOS 26, Liquid Glass)
├── 1. Профиль (главная)      — я, моя статистика, поездки, места, друзья; лента друзей — переходом отсюда
├── 2. Карта                  — слои, фильтры, поиск, чекин, новое место, запись трека
├── 3. Места                  — подборки, поиск, страница места
├── 4. Лайфхаки               — экипировка, чеклисты, статьи, справочник рыб, правила
└── [+] Действие              — Начать поездку · Чекин · Улов · Новое место · Фото
```

- **Кнопка «+»** — отдельная вкладка-действие (в DesignKit уже есть `PlusTabLabel` из Tenra).
  Раскрывает меню быстрых действий, доступное с любого экрана.
- **Активная поездка** — мини-плеер над таб-баром (`tabViewBottomAccessory`, iOS 26): время,
  дистанция, кнопки «пауза» и «стоп». Плюс Live Activity на экране блокировки и в Dynamic Island.
- **Колокольчик и настройки** — в навигационной панели «Профиля».
- **Поиск** — в «Карте» и «Местах» (единый поиск по местам, водоёмам и людям).

## Модель данных (словарь)

| Сущность | Что это | Ключевые связи |
|----------|---------|----------------|
| **Пользователь** | Аккаунт и профиль: имя, @username, аватар, город, активности, язык | Друзья, всё созданное |
| **Дружба** | Взаимная связь (запрос → принятие). Блокировка — отдельно | Пользователь ↔ Пользователь |
| **Зона** | Большой объект с границей: водоём (Капшагай), участок реки, нацпарк, запретная зона, погранзона. Ведётся редакцией | Правила, Места внутри |
| **Место** | Точка на карте: точка ловли, стоянка, платник, база, съезд/парковка, родник и т.д. Создаёт пользователь или редакция. Есть **видимость** | Зона (родитель), Чекины, Отзывы, Медиа, Треды |
| **Чекин** | «Я здесь»: место + время + (фото, заметка, улов, условия). Чекин с фото или условиями — это **отчёт**, он попадает в «свежее» места | Место, Поездка, Улов, Медиа |
| **Поездка** | Контейнер выезда: активность, время, GPS-трек, чекины, уловы, фото, участники, статистика | Трек, Чекины, Уловы, Медиа, Участники |
| **Трек** | Записанная GPS-линия поездки | Поездка |
| **Маршрут** | Запланированная линия (из планировщика, из чужого или своего трека, подход к месту), по ней можно вести навигацию | Место (цель), Автор |
| **Улов** | Вид рыбы, вес, длина, количество, снасть, приманка, отпущена ли, фото | Поездка, Чекин, Место, Вид рыбы |
| **Отзыв** | Оценка 1–5 + текст + фото + дата визита. Один на пользователя на место | Место |
| **Тред** | Обсуждение на странице места: тема и ответы | Место, Сообщения |
| **Медиа** | Фото или видео с геометкой | Место / Поездка / Улов / Отзыв / Сообщение |
| **Правило** | Ограничение: нерестовый запрет, запрет орудий, тариф нацпарка, режим погранзоны. Даты, источник, год | Зона |
| **Экипировка** | Предмет из личного снаряжения: категория, бренд, вес, фото | Чеклисты |
| **Чеклист** | Шаблон (редакционный или свой) и его экземпляр для конкретной поездки | Экипировка, Поездка |
| **Статья** | Редакционный лайфхак или гайд на трёх языках | Категории |
| **Вид рыбы** | Справочник: названия RU/KK/EN/лат., фото, промысловая мера, где и как ловить | Уловы, Места |
| **Подборка** | Редакционный список мест («Платники рядом с Алматы») | Места |
| **Достижение** | Бейдж или статус (в т.ч. «смотритель места») | Пользователь |
| **Жалоба** | Жалоба на контент или пользователя | Любой UGC |

**Видимость** есть у мест, поездок, чекинов, уловов, маршрутов и медиа:
`все` · `друзья` · `выбранные друзья` (1.1) · `только я`. Подробно —
в [05-cross-cutting.md](05-cross-cutting.md#приватность-и-видимость).

### Предлагаемый таймлайн (обсудить)

Нерестовый запрет на Капшагае заканчивается ~20 мая — это естественный повод для запуска
(«открытие сезона»).

| Период | Что делаем |
|--------|------------|
| Окт 2026 | Этап 3 (архитектура, стек) и Этап 4 (спецификации) |
| Ноя 2026 – фев 2027 | Разработка MVP; параллельно наполнение: 200+ мест, правила 2026, статьи, чеклисты, справочник рыб |
| Мар – апр 2027 | Закрытая бета (TestFlight) с 30–50 амбассадорами из рыболовных чатов; обновление правил на 2027 год (приказ выходит в марте) |
| ~20 мая 2027 | Публичный запуск к открытию сезона |

Если к марту MVP не успевает — режем в таком порядке: треды → следование по маршруту
(остаются «как добраться» и запись трека) → Live Activity → статьи (остаются чеклисты и правила).

## Метрики

- **North Star:** еженедельные активные участники — пользователи, сделавшие за неделю хотя бы
  один чекин, отчёт, поездку или отзыв.
- **Здоровье контента:** доля публичных мест со свежим отчётом (за 7 дней) в сезон.
- **Рост:** доля новых пользователей, пришедших по приглашению или шарингу; K-фактор.
- **Удержание:** W1 / W4 по когортам; доля пользователей с 2+ поездками за месяц в сезон.

Метрики каждой вкладки — в её документе.
