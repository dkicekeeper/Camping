# M2. Чекины и уловы

> Статус: **M2a (чекины, уловы, отчёты места) — ✅ проверено на iPhone (2026-09-29).**
> **M2b (фото) — код готов, ждёт проверки на iPhone.** Дальше: M2c — локальная база и
> офлайн-очередь.

Веха разбита на три части, чтобы каждую можно было проверить отдельно:

| Часть | Что | Статус |
|-------|-----|--------|
| **M2a** | Чекин «Я здесь» с условиями, уловы, справочник рыб, свежие отчёты в карточке места, «Мои уловы» в профиле | ✅ Проверено |
| **M2b** | Фото к чекину и улову: сжатие на телефоне, загрузка в Supabase Storage, видимость как у чекина | Код готов |
| **M2c** | Локальная база (GRDB) и офлайн-очередь: чекин и улов сохраняются без сети и уходят на сервер, когда сеть появится | После M2b |

## M2a. Чекины, уловы, отчёты

### Что делает приложение

| Где | Что |
|-----|-----|
| Карточка места | Кнопка **«Я здесь»** (для вошедших). Ниже — **«Свежие отчёты»**: автор (или «Вы»), значок подтверждения, сколько времени назад, условия («Клёв: хороший · Людей: немного»), заметка, уловы |
| Форма чекина | Условия чипами — клёв, людность, вода, дорога (повторный тап снимает выбор); уловы; заметка; «Кто видит». Всё необязательно — чекин за 10 секунд |
| Форма улова | Вид рыбы (16 видов региона и «другое»), вес, длина, количество, способ, приманка, «Отпустил», **«Скрыть вес и длину»** — другие увидят вид и количество, но не размер |
| Подтверждение | Телефон один раз определяет позицию. Если вы не дальше 500 м от места — чекин **подтверждён** (зелёная печать). Без геопозиции чекин сохраняется без подтверждения |
| Профиль | **«Мои уловы»** — последние 20 уловов с местом и датой. Обновляются при возврате на вкладку. Карточка «Сервер» — только если сервер не настроен или недоступен |

Правила видимости (как везде в приложении): чекин и улов не могут быть видимее места —
в месте «для друзей» публичный чекин станет «для друзей», в секретном — «только я». Координаты
чекина никому, кроме автора, не отдаются.

### Код

**База:** `migrations/…_catches_reports.sql`
- `fish_species` — справочник рыб на трёх языках (сазан, судак, жерех, сом, змееголов, щука,
  окунь, балхашский окунь, лещ, карась, толстолобик, белый амур, маринка, радужная форель,
  плотва, линь, «другое»), читать может и гость.
- `catches` — улов в чекине: вид, вес (г), длина (мм), количество, способ, приманка, отпущен,
  видимость, «скрыть размер». Триггер берёт место из чекина, проверяет, что чекин свой, и
  ограничивает видимость видимостью места.
- RPC `place_reports(p_place, p_limit)` — свежие чекины места с уловами, которые видит зритель;
  без координат; вес и длина скрытого чужого улова — `null`.
- RPC `my_catches(p_limit)` — свои уловы с названием места (если место ещё видно).
- Тесты: `tests/database/04_catches_reports.test.sql` — 22 проверки (справочник для гостя,
  привязка улова только к своему чекину, «не видимее места», скрытый размер, друг / чужой /
  гость, приватный чекин в публичном месте, «Мои уловы» недоступны гостю). Всего тестов базы — 81.
- Проверено и сквозным сценарием: JSON, который собирает приложение, вставлен так же, как это
  делает PostgREST (только разрешённые колонки), и прочитан через оба RPC тремя зрителями.

**iOS (`Packages/DaladaKit`):**
- `DaladaCore/Catch.swift` — `FishSpecies`, `FishingMethod`, `CheckinConditions` (незнакомые
  значения с сервера не ломают разбор), `CatchDraft` (кг → г, см → мм), `CheckinDraft`,
  `PlaceReport`, `MyCatch`; тесты `CatchTests`.
- `Backend/CheckinsAPI.swift` — справочник, отчёты, мои уловы, создание чекина с уловами.
  ID задаёт телефон: повторная отправка не создаёт дублей (задел для офлайн-очереди в M2c).
- `AppFeature` — `CheckinFormView` (с чипами `ChipRow`), `CatchFormView`, `DeviceLocation`
  (разовая геопозиция), `SpeciesStore` (справочник в памяти), обновлённые `PlaceCardView` и
  `ProfileHomeView`.

### Как проверить

1. `git pull` → Run (новые файлы — в пакете, `xcodegen` не нужен). Миграция применится к
   облачной базе сама после попадания в `main`.
2. Откройте своё место на карте → **«Я здесь»** → разрешите геопозицию.
3. Выберите «Клёв: хороший», «Людей: немного» → **«Добавить улов»** → щука, 2,5 кг, 65 см,
   «Отпустил» → «Готово» → ещё улов: окунь ×5 без веса → **«Отметиться»**.
4. В карточке — отчёт «Вы», условия и два улова. Если вы у места — зелёная печать; на
   симуляторе — Features → Location → Custom Location с координатами места.
5. «Профиль» → «Мои уловы»: щука и окунь с названием места.
6. Выйдите → карточка публичного опубликованного места показывает отчёт гостю (если чекин
   публичный); отчёты в местах «для друзей» гостю не видны.

Ошибки сборки — присылайте текст или скриншот.

## M2b. Фото

### Что делает приложение

| Где | Что |
|-----|-----|
| Форма чекина | Секция **«Фото»**: до 5 фото из галереи, превью с крестиком для удаления |
| Форма улова | **«Фото улова»** — одно фото; в списке уловов у такого улова значок камеры |
| Карточка места | Под отчётом — ряд превью; тап открывает фото на весь экран, листание свайпом |

**Сжатие и приватность.** Телефон уменьшает фото до 1600 px по длинной стороне (превью — до
400 px), поворачивает по EXIF и перекодирует в JPEG. В новый файл пишется только картинка:
геометка, модель телефона и время съёмки не загружаются. Фото весит примерно 200–400 КБ,
превью — 20–40 КБ.

**Кто видит.** У фото нет своей видимости: его видят те, кто видит чекин, место и улов (если
фото улова). Поменяли видимость чекина — поменялась видимость фото. Файлы лежат в закрытом
бакете, приложение получает на них временные ссылки (на час) — только на то, что зрителю
разрешено.

**Порядок сохранения:** чекин → уловы → файлы → записи о фото. Если сеть оборвалась на середине,
можно просто нажать «Отметиться» ещё раз: уже загруженное не задвоится.

**Место в хранилище.** Бесплатный план Supabase — 1 ГБ файлов, этого хватит примерно на
3 000 фото. Для беты достаточно; при переезде в Казахстан хранилище переедет вместе с базой.

### Код

**База:** `migrations/…_media.sql`
- `media` — фото: чекин, улов (необязательно), место (из чекина), размеры. Путь к файлу
  `<автор>/<id>.jpg` база вычисляет сама. Триггер: чекин и улов только свои, улов — из того же
  чекина, не больше 20 фото на чекин.
- Бакет `media`: закрытый, только JPEG, до 5 МБ на файл. Политики: загружать — только в свою
  папку и только `<id>.jpg` / `<id>_thumb.jpg`; читать — свои файлы и чужие, если видно фото
  (`private.media_visible`); удалять — свои.
- Политики хранилища выполняются от имени пользователя, а схема `private` для него закрыта,
  поэтому функция проверки для них — в отдельной схеме `rls` (через API она не доступна).
- RPC `place_reports` теперь отдаёт и `media`: пути к фото и превью, размеры.
- Тесты: `tests/database/05_media.test.sql` — 30 проверок (автор / друг / чужой / гость /
  заблокированный × фото публичного чекина, чекина для друзей, места для друзей, приватного
  улова, места на модерации, удалённое фото, файл без записи; загрузка в чужую папку и с чужим
  именем; фото в отчётах). Проверено, что тесты ловят поломку политик. Всего тестов базы — 111.

**iOS (`Packages/DaladaKit`):**
- `DaladaCore/Media.swift` — `PhotoDraft`, `MediaPath` (пути в нижнем регистре, как в базе),
  `ReportMedia`; фото в `CheckinDraft` и `CatchDraft`; тесты `MediaTests`.
- `Backend/CheckinsAPI.swift` — загрузка файлов и записей о фото при сохранении чекина,
  подписанные ссылки одним запросом.
- `AppFeature/PhotoCompressor.swift` — уменьшение и перекодирование (ImageIO) вне главного потока.
- `AppFeature/PhotoViews.swift` — превью в формах, ряд фото в отчёте, просмотр на весь экран,
  кэш картинок в памяти (одно фото за сессию скачивается один раз).

### Как проверить

1. `git pull` → Run.
2. Своё место → «Я здесь» → «Добавить фото» → выберите 2–3 фото → превью появились, одно
   удалите крестиком.
3. «Добавить улов» → «Добавить фото» → фото рыбы → «Готово»: у улова значок камеры.
4. «Отметиться» (с фото сохранение занимает несколько секунд) → в отчёте ряд превью → тап →
   фото на весь экран, свайп — следующее.
5. Приватность: Supabase → Storage → `media` → скачайте одно фото на Mac → откройте в
   «Просмотре» → Инструменты → Показать инспектор: вкладки GPS нет.
6. Если есть второй аккаунт: чекин «Только я» с фото — второй аккаунт его не видит.
