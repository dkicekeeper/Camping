# M13. Достижения

> Статус: **в TestFlight 123.** Из плана (`docs/02-plan/01-profile.md`, «Достижения», и
> `docs/02-plan/05-cross-cutting.md`, «Геймификация»): 8–10 простых значков — первые шаги, водоёмы,
> дистанция, ночёвки, вклад в общую базу.

## Что видит человек

«Профиль» → внизу раздел **«Достижения»**: последние полученные значки, строка «Ближе всего» — значок,
до которого осталось меньше всего, с полоской прогресса, и «Получено N из 10». «Все» — сетка всех значков:
полученные цветные, остальные серые, под ними — сколько осталось. Нажатие на значок — что нужно
сделать, прогресс или дата получения.

Новый значок — лист поздравления, когда открыт «Профиль» (если значков несколько — все сразу). Без сети
раздел показывает сохранённые значки, без поздравления.

## Значки

| Значок | Условие | Цель |
|--------|---------|------|
| Первая поездка | Завершённая записанная поездка | 1 |
| Сотня | Километры в записанных поездках | 100 км |
| Под звёздами | Ночёвки: смены даты по Алматы внутри поездки (не больше 14 за поездку — забытая запись не даёт значок) | 5 |
| Первый улов | Улов | 1 |
| Пять видов | Разные виды рыбы (без «другой рыбы») | 5 |
| Трофей | Одна рыба от 3 кг (запись с несколькими рыбами не в счёт) | 3 кг |
| Путешественник | Разные места с отчётами | 5 |
| Первооткрыватель | Своё публичное место, прошедшее проверку | 1 |
| Знаток | Отзывы о местах | 5 |
| Помощник редакции | Правка места, которую приняла редакция | 1 |

Считаются только свои неудалённые записи любой видимости. Полученный значок остаётся, даже если потом
удалить поездку или улов.

## Приватность

Значки видны **только владельцу**: часть условий считается по приватным данным (ночёвки, уловы в
секретных местах), а значок у друга косвенно рассказал бы о них. Показ значков друзьям — отдельное
решение позже (вместе с выбором, какие значки показывать).

## Как устроено

- Таблица `public.achievements` (владелец, код, `earned_at`, `seen_at`): RLS — только свои строки, писать
  клиенту нельзя.
- `private.achievement_progress(user)` — прогресс по всем значкам одним запросом.
- `public.my_achievements()` — выдаёт заработанные с прошлого раза и возвращает все значки с прогрессом,
  датой получения и признаком «новый»; `public.mark_achievements_seen()` — поздравление показано.
- Миграция `…_achievements.sql`, тесты `29_achievements.test.sql` (прогресс, ограничения условий,
  «новые», значок остаётся после удаления, чужие значки не видны, без входа нельзя).
- iOS: `DaladaCore/Achievements.swift` (модель, коды, единицы прогресса), `Backend/AchievementsAPI.swift`,
  `AppFeature/AchievementsViews.swift` (раздел профиля, сетка, подробности, поздравление). Значок —
  `IconView` из DesignKit в круге цвета из палитры DesignKit.

Новый значок на сервере, о котором старое приложение не знает, просто не показывается.

## Как проверить

1. «Профиль» → «Достижения»: у нового аккаунта — «Получено 0 из 10» и «Ближе всего».
2. Записать короткую поездку → вернуться в «Профиль»: поздравление «Новое достижение — Первая поездка».
   Закрыть — при следующем открытии поздравления нет.
3. «Все» → нажать на серый значок «Сотня»: условие и «N из 100 км».
4. Удалить поездку — значок «Первая поездка» остаётся.
