|-------|-----|--------|

## M3a. Запись и поездки

### Что делает приложение

| Где | Что |
|-----|-----|
| «+» → «Начать поездку» | Вид: рыбалка, кемпинг, поход, другое → «Старт». Без входа — «Нужен вход» |
| Экран записи | Карта следует за вами, линия трека. Время, дистанция, скорость, набор высоты. «Пауза» / «Продолжить», «Финиш». «Свернуть» (стрелка вниз) — запись продолжается |
| Мини-плеер | Над вкладками, пока идёт запись: время и дистанция, тап — экран записи (iOS 26.1+; на 26.0 — через «+» → «Идёт запись поездки») |
| Фон | Трек пишется с выключенным экраном и в другом приложении, без связи. В статус-баре — синий индикатор геопозиции. Хватает разрешения «При использовании» |
| Финиш | Итоги (дистанция, в движении, всего, набор высоты), название («Рыбалка · 29 сентября»), вид, заметка, кто видит; «Сохранить» или «Удалить поездку». «Назад» — вернуться к записи (она на паузе) |
| Сохранение | Поездка ложится в офлайн-очередь и уходит на сервер, когда есть сеть; до этого — в профиле в «Ожидают отправки» |
| Профиль | «Мои поездки» — последние три и «Все». Страница поездки: трек на карте, итоги, максимальная скорость, заметка, чекины за время поездки с уловами |

**Надёжность.** Каждая точка сразу пишется в SQLite на телефоне. Если приложение закрыли или
система его выгрузила, при следующем запуске запись продолжается с того же места (разрыв не
добавляется к дистанции).

**Какие точки пишутся.** Точность не хуже 50 м; «прыжки» быстрее 250 км/ч отбрасываются; стоя
на месте — точка раз в минуту, а не каждую секунду. Время в движении не считает стоянки
(медленнее 0,4 м/с) и паузы. Набор высоты — по GPS с порогом 4 м, чтобы шум не накручивал метры
(барометр — в M3b).

**Кто видит.** Пока поездки видит только автор. Поле «Кто видит» сохраняется уже сейчас (по
умолчанию «Только я»); делиться поездками с друзьями — в M4, вместе с зонами приватности (скрыть
начало и конец трека у дома).

### Код

**База:** `migrations/…_trips.sql` — таблица `trips`: вид, название, заметка, начало и конец,
итоги, трек `LineStringZM` (долгота, широта, высота, время каждой точки), видимость. Только свои
строки; трек после сохранения не меняется; не больше 150 000 точек. RPC `my_trip_checkins` — свои
чекины за время поездки (название места — пока оно видно). Тесты — `07_trips.test.sql`
(14 проверок), всего тестов базы — 133. Сквозная проверка: JSON поездки из приложения вставлен
так же, как это делает PostgREST; дистанция телефона 950 м против 951 м по PostGIS.

**iOS (`Packages/DaladaKit`):**
- `DaladaCore/Trip.swift` — точка трека, фильтр, итоги (`TrackStats`), черновик поездки,
  кодирование трека в EWKT, модели списка и страницы поездки; тесты `TripTests`.
- `Persistence` — вторая версия схемы: идущая поездка, точки трека, очередь поездок
  (`TripStore`); тесты — запись переживает переоткрытие базы, финиш переносит поездку в очередь.
- `Sync` — поездки отправляются перед чекинами; протокол `OutboxSending`.
- `Backend/TripsAPI.swift` — список, страница с треком, чекины поездки, создание.
- `MapEngine` — слой трека, камера «следовать за мной» и «весь трек».
- `AppFeature` — `TripRecorder` (`CLLocationUpdate.liveUpdates`, `CLBackgroundActivitySession`),
  экраны старта, записи, финиша, мини-плеер, «Мои поездки», страница поездки.
- `Dalada/Info.plist` — `UIBackgroundModes: location`.

### Как проверить

1. `git pull` → Run на iPhone (на симуляторе — Features → Location → City Run / Freeway Drive).
2. «+» → «Начать поездку» → «Рыбалка» → «Старт» → разрешите геопозицию.
3. Пройдитесь 5–10 минут: линия на карте, время и дистанция растут. Заблокируйте телефон на
   пару минут — трек продолжается (синий индикатор в статус-баре).
4. «Свернуть» → над вкладками мини-плеер → тап — снова экран записи.
5. «Пауза» → отойдите → «Продолжить»: отрезок на паузе не добавился к дистанции.
6. Во время поездки отметьтесь в месте («Я здесь»).
7. «Финиш» → название, «Сохранить» → «Профиль» → «Мои поездки» → поездка: трек, итоги и ваш
   чекин.
8. Без сети: авиарежим → короткая поездка → «Сохранить» → в профиле «Ожидают отправки» → сеть →
   поездка уходит.
9. Смахните приложение во время записи и откройте снова — запись продолжается.

## M3b. Статистика и Live Activity

### Что делает приложение

| Где | Что |
|-----|-----|
| Профиль | Под шапкой — **дней на природе · поездок · км в поездках · уловов**. Без сети — сохранённые числа; обновляются, когда очередь ушла на сервер |
| Экран блокировки | Пока идёт запись — Live Activity: вид поездки, время (идёт само), дистанция, «На паузе» |
| Dynamic Island | Значок поездки и дистанция; по нажатию и удержанию — время и дистанция крупно |

**День на природе** — календарный день по времени Алматы, в который была поездка (у кемпинга
с ночёвкой — каждый её день) или чекин. Удалённые поездки и чекины не считаются.

Дистанция в Live Activity обновляется не чаще раза в 15 секунд (так экономится заряд), пауза
и продолжение — сразу. Если приложение выгрузили и оно поднялось снова, запись подхватывает ту же
Live Activity.

### Код

- База: `migrations/…_stats.sql` — RPC `my_stats` (только свои строки); тесты `08_stats.test.sql`
  (7 проверок), всего тестов базы — 140.
- `Packages/DaladaKit/Sources/TripLiveActivity` — атрибуты и вид Live Activity (общие для
  приложения и расширения); `AppFeature/TripLiveActivityController.swift` — запуск, обновления,
  завершение.
- `ios/DaladaWidgets` — расширение виджетов (новый таргет в `project.yml`); у приложения
  включён `NSSupportsLiveActivities`. После `git pull` хук пересоздаст проект (или
  `cd ios && xcodegen generate`).

### Как проверить

1. `git pull` → проект пересоздастся сам (новый таргет) → Run на iPhone.
2. «Профиль»: карточка «дней на природе · поездок · км · уловов».
3. Начните поездку → заблокируйте телефон: на экране блокировки — Live Activity с временем и
   дистанцией. На iPhone с Dynamic Island — значок и дистанция вверху.
4. «Пауза» в приложении → на экране блокировки «На паузе». «Финиш» → Live Activity исчезает.
5. Если Live Activity не видно: Настройки → Dalada → Live Activity — включить.
