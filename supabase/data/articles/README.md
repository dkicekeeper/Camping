# Статьи и советы

Исходники статей для миграции `migrations/…_articles.sql`: по файлу на язык — `<id>.ru.md`,
`<id>.kk.md`, `<id>.en.md`; категория, порядок и дата — в `index.json`.

```
---
title: Заголовок
summary: Одна-две фразы для списка статей.
---
Текст статьи.
```

## Разметка

Приложение показывает подмножество Markdown:

| Что | Как |
|-----|-----|
| Заголовок раздела | `## Заголовок`, подраздел — `### Заголовок` |
| Абзац | Строки подряд; пустая строка — новый абзац |
| Список | `- пункт` |
| Шаги | `1. шаг` |
| Выноска (предупреждение, совет) | `> текст` |
| Внутри строки | `**жирный**`, `*курсив*`, `[ссылка](https://…)` |

Нельзя: картинки, HTML, таблицы, заголовок `#`, вложенные списки, блоки кода — `build_sql.py`
остановится с ошибкой.

## Как добавить или поправить статью

```bash
python3 supabase/data/articles/build_sql.py > /tmp/articles.sql
```

Новая статья — новой миграцией с `insert` (уже применённые миграции не редактируем), правка —
`update public.articles set body_ru = $md$…$md$ where id = '…'`. Черновик — `is_published = false`:
в приложении его не видно. Небольшие правки можно делать прямо в Supabase Studio — приложение
подхватит их в течение часа.

Категории: `tackle` (снасти и приманки), `knots` (узлы), `technique` (техника ловли), `cooking`
(приготовление улова), `safety` (безопасность), `rules_ethics` (правила и этика), `places_seasons`
(места и сезоны).

Казахский и английский тексты первых статей — черновик на вычитку носителем.
