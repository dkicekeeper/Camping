# Места редакции

Места, которые Dalada показывает всем с первого дня, — от служебного аккаунта редакции **@dalada**
(`private.editorial_id()`, миграция `…_editorial.sql`). Войти в него нельзя; в карточке такого места
приложение пишет «Редакция Dalada», а у мест из OpenStreetMap — «Данные: © участники OpenStreetMap».

| Файл | Что |
|------|-----|
| `places.csv` | **Все места редакции** — единственный источник. Правки — здесь |
| `places.py` | Проверка таблицы, импорт из Google My Maps и CSV, сборка миграции |
| `osm_candidates.csv` | Кандидаты из OpenStreetMap с решением: `yes` — взято, `?` — посмотреть, `no` — нет |
| `fetch_osm.py` | Обновить кандидатов из OpenStreetMap (решения в файле сохраняются) |

## Колонки places.csv

| Колонка | Что |
|---------|-----|
| `id` | UUID места. Не меняйте — по нему миграция находит место |
| `type` | `fishing_spot` точка ловли, `water_body` водоём, `campsite` стоянка, `paid_pond` платник, `base` база отдыха, `parking` съезд/парковка, `spring` родник, `tackle_shop` снасти, `landmark` достопримечательность |
| `name` | Название, до 80 символов |
| `lat`, `lon` | Широта и долгота (43.353722, 78.505530) — в Алматинской области, Жетісу или Алматы |
| `access_lat`, `access_lon` | Точка подъезда (необязательно), не дальше 20 км |
| `description` | Описание, до 2000 символов (необязательно) |
| `source` | Откуда: `osm:w123` — OpenStreetMap, иначе — редакция (например, `import:my_map.kml`) |

Места редакции всегда публичные и точные. Не добавляйте «секретные» места рыбаков — только
общеизвестные: водоёмы, платники, базы, стоянки, родники, магазины.

## Как добавить места

**Google My Maps** (удобно с телефона): карта, слои по типам — «Точки ловли», «Водоёмы»,
«Стоянки», «Платники», «Базы», «Съезды», «Родники», «Снасти», «Достопримечательности» (достаточно
части слова, на русском, казахском или английском). Меню карты → «Экспорт в KML/KMZ», затем:

```bash
python3 supabase/data/places/places.py import ~/Downloads/map.kmz
python3 supabase/data/places/places.py import extra.kml --type campsite   # слой без понятного названия
```

**Таблица** (Google Таблицы → Скачать → CSV) с колонками `type,name,lat,lon` (и при желании
`description,access_lat,access_lon`):

```bash
python3 supabase/data/places/places.py import new_places.csv
```

**Из OpenStreetMap**: в `osm_candidates.csv` поставьте `yes` нужным строкам (ссылка `link` открывает
объект на карте OSM), затем `places.py import supabase/data/places/osm_candidates.csv` — уже
добавленные пропускаются.

Импорт пропускает повторы (то же место того же типа ближе 300 м) и пишет новые строки в
`places.csv`. Названия и описания после импорта можно поправить прямо в таблице.

## Как выкатить

```bash
python3 supabase/data/places/places.py migration   # новая миграция …_editorial_places.sql
python3 supabase/data/places/places.py check       # то же проверяет CI
```

Миграция добавляет новые места, обновляет изменённые и скрывает (`deleted_at`) те, что убраны из
таблицы. Скрытие и статус, поставленные модератором в Studio, она не трогает. После `main`
миграцию применяет GitHub-интеграция Supabase — места появятся в приложении сразу. CI падает, если
`places.csv` изменена, а миграция не собрана.

## Первая выборка (M6e)

165 мест из OpenStreetMap (данные на 30.09.2026): 86 водоёмов (озёра и водохранилища с названием,
без технических и безымянных), 23 водопада, 23 родника и горячих источника, 21 стоянка (поляны и
кемпинги у Алматы, Чарын, Топарские озёра), 5 мест рыбалки, 3 платника, 3 магазина снастей, база
«Рыбацкая деревня». Точка водоёма — внутри контура; описания — только из данных OSM на русском или
казахском (питьевая ли вода, адрес, часы работы).

Что стоит посмотреть редакции: `?` в `osm_candidates.csv` (базы отдыха на Алаколе и Капшагае, приюты
в горах, пруды), описания популярных водоёмов (что ловится, как подъехать) и точки подъезда.
