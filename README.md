# Dalada

**Dalada** (каз. «далада» — «на природе») — iOS-приложение для поездок на природу: рыбалка,
кэмпинг, походы в горы, дикая природа. Старт — **рыбалка** в **Алматы, Алматинской области и
области Жетісу**, дальше другие активности и регионы. Языки: русский, казахский, английский.

Формула продукта: **Strava** (профиль, поездки, статистика, друзья) + **Foursquare/Swarm**
(места, чекины, краудсорсинг) + локальная специфика Казахстана (водоёмы, запреты, нацпарки,
погранзона).

## Разделы приложения

| # | Вкладка | Суть |
|---|---------|------|
| 1 | **Профиль** | Данные пользователя, маршруты, статистика (км, поездки, уловы), любимые места, друзья, фото, привязанные к местам и поездкам |
| 2 | **Карта** | Алматы и область, места, чекины, краудсорсинг, прокладка маршрута |
| 3 | **Места** | Популярные, где были друзья, рекомендуемые; страница места: отзывы (1–5), фото/видео, обсуждения-треды |
| 4 | **Лайфхаки** | Советы, моя экипировка, чеклисты «что не забыть» |

## Дизайн-система

UI строится на [DesignKit](https://github.com/dkicekeeper/DesignKit) — SwiftUI-дизайн-системе,
вынесенной из приложения Tenra (iOS 26+, Liquid Glass, шрифт Inter). Заметки о том, что из неё
переиспользуем и что придётся добавить, — в [брифе](docs/00-product-brief.md#дизайн-система-designkit).
